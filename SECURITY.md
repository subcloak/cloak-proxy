# Security

Please report security issues in Cloak Proxy privately, not in a public issue.

- Disclosure policy and contact: https://subcloak.com/security
- security.txt: https://subcloak.com/security.txt

Include the Cloak Proxy version (Cloak Proxy › About Cloak Proxy), your macOS version, and steps to reproduce. We reply within a few working days.

How Cloak Proxy handles your traffic, certificates and secrets: https://docs.subcloak.com/cloak-proxy/reference/security-and-privacy/
